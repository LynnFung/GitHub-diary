# 2026-05-18 — 体验微信小游戏开发

今天尝试用“扣子”（字节的 Solo）这款编程软件，做了一个微信小程序的小游戏。把在 Solo 里做好的项目复制到微信开发者工具后，出现了很多错误，导致小程序无法正常运行。不过在这个过程中，我学到了整个开发流程：

- 从创建项目、编辑代码到在开发者工具中调试的步骤；
- 微信小游戏/小程序的发布流程，似乎需要等待十多天的审核时间，发布过程比较繁琐；
- 微信小游戏主要使用 JavaScript 作为编程语言；
- 通过文件后缀名可以判断每个文件的用途，这让我对项目结构和程序的基本概念有了初步认识。

虽然这次没有成功发布，但我体验了完整的流程，收获了许多实践上的理解。下一步我想尝试用 Python 做一个本地软件，或者做一个可以发布到网页上的东西；或者继续做微信小程序，把发布流程搞通。也想尝试一些新的工作流工具（比如 Gear），明天可以试试使用 Agent 和 Skill 来做一些自动化或辅助流程。

今天就写到这里。继续探索。
